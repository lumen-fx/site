# Lumen documentation

The Lumen documentation is moving to Zensical and will appear here.

Lumen is a Rust desktop UI framework with web-like authoring: `.lmn` markup and
real CSS, compiled by `lumenc` and run on a native runtime.

While the migration is in progress, this section is a placeholder. The build
pipeline already reserves this slot, so the Lumen docs will slot in with no
structural change once they are Zensical markdown.

In the meantime:

- [Candela documentation](../candela/docs/) -- the scripting language Lumen uses.
- [Lumen on GitHub](https://github.com/lumen-fx) -- source and issues.
